# ResortEmpireRRH

Školský projekt v spolupráci s RRH.

## Project Information

- **Unity:** 6000.6.8f1
- **Render Pipeline:** URP
- **Platform:** Android (Landscape)

## Getting Started

1. Otvor projekt v Unity Hub pomocou Unity 6000.6.8f1.
2. Otvor scénu `Assets/Scenes/Game.unity`.
3. Spusti Play Mode.
